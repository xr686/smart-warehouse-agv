## 二、主控载板（P3509-A01）接口占用

| 接口 | 类型 | 本系统连接设备 |
|---|---|---|
| J6 上（USB 3.1 Type-A） | USB 上行 | N10P 雷达串口转 USB 适配板（→ /dev/ttyACM1） |
| J6 下（USB 3.1 Type-A） | USB 上行 | reCamera（RNDIS 虚拟网卡） |
| J7 上（USB 3.1 Type-A） | USB 上行 | USB 转 RS485 模块（→ /dev/ttyACM0，电机总线） |
| J15（RJ45） | 千兆网口 | 路由器 / 调试 PC |
| J16（DC 座 2.5×5.5×9.5mm 中心正） | 供电输入 9–20V | 12V 聚合物锂电池 |
| J12（40-pin） | GPIO/I2C/SPI/UART | 未使用 |
| J5（Micro-USB） | Device 模式 | 刷机调试用 |

> 注：J6/J7 每两个端口共享一组 USB 3.1 控制器，每堆栈总供电限制 1A。

## 三、供电架构小结

- **弱电回路**：12V/9000mAh 锂电 → DC 口 → Jetson NX（独立供电，防电机浪涌）
- **动力回路**：100W PD 充电宝 → CH224K 诱骗 15V → XT60 → RoboMaster 分电板 → 2×XT30(15A) → DDSM115 电机（额定 18V，工作范围 12–24V，15V 可用）
- 双电源物理隔离，斩断电机浪涌对弱电控制系统的干扰
